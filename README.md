# GB Institutional Ratings

**Who still holds?**

Comparative website tracking the health of 13 core UK institutions.

## Dual-track model

- **Formal ratings** (authoritative): Full five-pillar assessments, updated quarterly for UK institutions and their international peers.
- **Weekly Trust-Pressure Signal** (provisional): Directional indicator (Positive / Neutral / Negative) focused on short-term Public Trust for UK institutions only.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Data

Institution ratings, baselines, peers and weekly signals are defined in `data/institutions.ts`.
